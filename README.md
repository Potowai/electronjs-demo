# Electron Demo

Application de bureau **Electron** avec **Vue** et **UIKit** — démonstration du
cycle de vie d'une application de bureau et de son packaging multi-plateforme.

## Fonctionnalités

- Process principal, preload et renderer séparés
- Routage côté renderer avec `vue-router`
- Composants UIKit
- Packaging et publication automatisés

## Stack

- **Electron**
- **Vue** 3 + **vue-router**
- **UIKit** — composants

## Démarrage

```bash
npm install
npm start
```

## Scripts

| Commande | Rôle |
| :--- | :--- |
| `npm start` | Lance l'application |
| `npm run package` | Empaquette l'application |
| `npm run make` | Génère les installeurs |
| `npm run publish` | Publie la version |
| `npm run lint` / `npm run format` | Qualité de code |
